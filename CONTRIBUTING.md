# Contributing

Thanks for your interest in contributing to **rl-anti-money-laundry**.

## Dev setup

See [README.md](README.md) for environment setup (Gymnasium env, FastAPI backend, React dashboard).

## Before you open a PR

- Add or update tests for any behavior change; run `pytest` (see [pytest.ini](pytest.ini)) before submitting.
- Keep [ARCHITECTURE.md](ARCHITECTURE.md) and `docs/` in sync with code changes.
- Use clear, descriptive commit messages.

## Reporting bugs / requesting features

Use the issue templates under [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE). For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
